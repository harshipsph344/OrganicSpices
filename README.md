\# 🌿 OrganicSpices



OrganicSpices is a full-stack e-commerce web application for browsing and purchasing organic spices, vegetables, and herbs.



The project includes user registration and login, product browsing, cart management, wishlist, checkout, order tracking, and a Django admin panel for managing backend data.



\## 🚀 Live Demo



\- \*\*Frontend:\*\* https://organispices.netlify.app

\- \*\*Backend API:\*\* https://organicspices.onrender.com

\- \*\*Admin Panel:\*\* https://organicspices.onrender.com/admin/



\## ✨ Features



\### 👤 User Management

\- User registration

\- User login

\- User profile

\- Phone and address management



\### 🌿 Products

\- View available products

\- Product categories

\- Product price and stock

\- Product images and descriptions



\### 🛒 Shopping Cart

\- Add products to cart

\- Increase quantity

\- Decrease quantity

\- Remove products

\- Cart data stored in backend



\### ❤️ Wishlist

\- Add products to wishlist

\- Remove products from wishlist

\- Wishlist persistence



\### 📦 Orders

\- Checkout from cart

\- Create orders

\- View order history

\- View order items

\- Track order status



\### 🔐 Admin Panel

\- Manage users

\- Manage user profiles

\- Manage products

\- Manage cart items

\- Manage orders

\- Manage order items
